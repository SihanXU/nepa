# NEPA Project Page Template

This repository contains the **project-page template of [NEPA](https://sihanxu.me/nepa)**, designed by **[Si.X](https://sihanxu.me/)**.

- Live demo / example: https://sihanxu.me/nepa  
- Designer: https://sihanxu.me/

## ✅ Usage (Adopt this template)

You are welcome to **adopt this template for your own project page**.

**Attribution requirement (must keep):**
- Please **keep the credit line** such as **“Designed by Si.X”** (or an equivalent attribution) in an appropriate place (e.g., footer, README, or credits section).
- If you modify the template, please also note that it is adapted from this template and keep the original attribution.
